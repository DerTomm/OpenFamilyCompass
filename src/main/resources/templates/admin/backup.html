Restore Backup
Restore a backup to recover your database to a previous state. The backup file must be compatible with the current application version.
Warning: Restoring a backup will overwrite all current data in the database. Make sure to create a fresh backup before proceeding if you want to keep the current data.
Information

About Backups:

  • Backups include all database tables and data
  • Metadata (migration level, timestamp) is stored in the backup for compatibility verification
  • Backups are compressed as ZIP files for efficient storage and transfer
  • The application version at backup time is recorded for compatibility checking

Before Restoring:

  • Ensure you have a backup of current data if needed
  • Verify the backup file is from a compatible application version
  • Close all user sessions if possible to avoid conflicts
  • The restore process will clear existing data and reload from the backup

Backup File Naming:

Backup files are automatically named with a timestamp: backup_YYYYMMDD_HHmmss.zip
