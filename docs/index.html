🧭 OpenFamilyCompass

Guiding children's behavior and family routines — together.

OpenFamilyCompass is an open-source web application designed for parents to manage kids chores and promote good behavior. It combines task management, behavior points, and a reward system in a child-friendly, intuitive interface.

👨‍👩‍👧‍👦 Multi-User System

Three roles: Admin, Parents, and Children with appropriate permissions and interfaces.

📝 Task Management

Create one-time and recurring tasks (daily, weekly, monthly) with automatic scheduling.

⭐ Points System

Flexible point allocation by parents for completed tasks and positive behaviors.

🛍️ Reward Shop

Children can redeem their earned points for rewards defined by parents.

💚 Habit Tracking

Track and reward positive behaviors to encourage good habits.

📊 Points History

Complete accountability with full history of all point transactions.

🛠️ Technology Stack

Java 21 Spring Boot PostgreSQL Thymeleaf Bootstrap Docker Maven Android/Kotlin
